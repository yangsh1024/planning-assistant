# 微信小程序端架构说明

## 技术选型

| 领域 | 选型 |
|------|------|
| 框架 | 原生微信小程序 |
| 请求封装 | 统一 `utils/request.js`，自动附加 `Authorization: Bearer <token>`；根地址配置在本机 `utils/config.js` |
| 状态管理 | globalData（轻量，原生支持） |

## 页面结构

```
pages/
├── login/          # 微信授权登录（code2session → JWT）
├── home/           # 当月预算执行总览（科目卡片 + 记一笔入口）
├── expense/
│   ├── add/        # 新增/编辑开销（含科目选择/创建、日期选择）
│   └── stats/      # 账单统计（统计 Tab + 流水 Tab）
├── plan/
│   └── edit/       # 月度预算编辑（科目排序 + 自定义科目 + 继承逻辑）
├── profile/        # 我的（头像昵称编辑 + 客服入口）
├── auth/
│   └── web-login/  # 网页版 Agent 登录确认 / 扫码兜底
└── agreement/      # 用户协议 / 隐私政策
```

阶段二新增 `pages/auth/web-login/web-login`：由固定小程序码打开，用户输入电脑端展示的六位登录码后查看设备摘要并确认/拒绝网页登录。「我的」页的“网页版 Agent”入口只复制一次性链接，不使用 `web-view` 或尝试拉起系统浏览器，入口文案不使用「打开浏览器」。

## 登录流程

```
小程序 wx.login() → 获取 code
    → POST /api/user/login { code }
    → 服务端 code2session 换取 openid
    → 返回 JWT
    → 本地存储，后续请求头携带
    → Token 失效（401）→ 跳回登录页
```

## 关键业务逻辑

**预算前置拦截（两级）：**
1. 点击「记一笔」时，先调 `GET /api/plan/has-any` 检查是否从未设置过预算；若从未设置，强制跳转预算编辑页，不给跳过选项
2. 提交记账时，若记账日期所在月无预算配置，弹窗提示「去设置」或「直接保存」；选「直接保存」后按当前用户与月份写入本地标记，同月后续新增记录不再重复弹窗

**账单统计 Tab 预算使用率模块：** 统计 Tab 额外调用 `GET /api/plan/{yearMonth}/summary`；接口始终返回汇总，`totalBudget` 为 `0.00`（当月无预算）时隐藏该模块；使用率 > 100% 时进度条和百分比标红。统计 Tab 的三项汇总（总支出、总笔数、日均支出）来自 `GET /api/expense/stats/{yearMonth}` 的 `grandTotal / totalCount / dailyAvg` 字段。

**科目顺序：** 预算编辑页支持长按拖动排序：拖动项使用 `transform` 跟随手指，目标区间内的条目平滑让位，松手后才重排数据；保存时携带 `sortOrder`。首页科目卡片、记账科目选择、账单统计均按该顺序渲染，不做前端重排

**年月选择：** 首页、预算编辑和账单均复用 `date-picker` 的 `month` 模式，使用年份切换和 12 个月矩阵，不维护超长月份下拉列表。预算编辑在用户取消未保存变更时会将选择器回退到当前月份。

**首页明细入口：** 首页科目卡片为只读展示，不绑定跳转；「点击查看明细」统一跳转至账单流水 Tab，携带当前月份且默认展示全部科目。

**新增开支金额：** `amount-input` 使用原生 `input type="digit"` 调起系统数字键盘，输入值以字符串向页面回传，允许清空并保持两位小数校验规则。

**月份归属：** 所有月份统计、筛选以 `expenseDate` 所在月为准；日期选择器上限为今天，不允许选未来日期

**预算继承：** 打开新月份预算编辑时，调 `GET /api/plan/{yearMonth}` 返回 null，则向前查找最近有数据的月份加载；显示提示横幅「已展示最近一次预算，可直接修改后保存」

**月份切换拦截：** 预算编辑页有未保存更改时，切换月份弹窗确认，选「是」丢弃并切换，选「否」留在当前月

**客服入口：** 「我的」页通过 Modal 展示内置公众号二维码资源；长按二维码可使用微信图片菜单。

**网页版 Agent：** 个人主体小程序不使用 `web-view`，也不尝试直接拉起系统浏览器。已登录用户在「我的」页生成 60 秒有效、单次使用的链接并通过 `wx.setClipboardData` 复制；链接不含长期 JWT。用户在浏览器粘贴后，Web 以一次性短票据换取安全 Cookie。

**网页登录确认：** 固定小程序码直接打开确认页；用户输入电脑端显示的六位登录码，加载设备摘要后确认或拒绝。固定码流程须在发布前真机验收。

**资料编辑：** 头像只使用小程序包内的九种卡通小猫资源，以 3×3 九宫格展示；服务端保存其 key。用户在编辑面板中选择并通过 `PUT /api/user/profile` 保存。头像统一为 128×128 PNG，以兼顾真机兼容性和小程序包体；昵称输入框使用 `type="nickname"`，由微信在用户聚焦后提供昵称快捷填入，也可直接自定义；不调用 `wx.getUserProfile`，不读取微信头像，也不提供本地图片选择或上传。

**错误提示：** 请求层统一将网络失败映射为「网络异常，请稍后重试」、5xx 映射为「服务器异常，请稍后重试」；页面加载错误仍保留页面内重试入口。

**服务地址：** `utils/config.js` 为实际运行配置，已在仓库 `.gitignore` 中忽略；首次获取代码时从 `utils/config.example.js` 复制后填写。真机、体验版和正式版必须使用微信后台已登记的 HTTPS 域名。

**开发工具 AppID：** 在本机 `project.private.config.json` 配置 `appid`，该私有配置会覆盖公共项目配置，且已被 `.gitignore` 忽略。首次获取代码后，可在微信开发者工具「详情 → 基本信息」填写 AppID。

## 接口约定

- 统一响应体：`{ code, message, data }`
- 分页参数：`page`（从 1 开始）、`pageSize`
- 日期格式：`yyyy-MM`（年月）、`yyyy-MM-dd`（日期）
- 金额单位：元，保留两位小数，禁止直接用 `toFixed(2)` 处理浮点数

## 验证方式

微信开发者工具联调：登录获取 JWT → 设置预算 → 录入开销 → 查看首页总览 → 查看账单统计
